# Linux Server Administration Lab

## Overview

A hands-on Linux server administration project completed in a virtualized Linux environment. The project focuses on user and group management, file permissions, secure remote access, and firewall configuration.

## Environment

* **Operating System:** Red Hat Enterprise Linux (RHEL)
* **Virtualization:** Oracle VirtualBox
* **Shell:** Linux Command Line

## Tasks Performed

### 1. User & Group Management

* Created and managed user accounts
* Created groups for role-based access
* Added users to appropriate groups
* Configured file and directory ownership

### 2. File Permissions

* Configured role-based access using Linux file permissions
* Used `chmod` to modify permissions
* Used `chown` to manage ownership
* Verified permissions using Linux commands

### 3. SSH Configuration

* Configured SSH for secure remote access
* Managed the SSH service
* Verified SSH service status

### 4. Firewall Configuration

* Configured firewall rules using `firewalld`
* Allowed required services through the firewall
* Verified active firewall services
